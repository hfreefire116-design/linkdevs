How it works

Three steps to a locked link

No code, no sign-up. Open the Admin Panel and you're ready to go.

Step 1
Set your content
Choose what to hide — a destination URL, a randomly generated secret key, or a block of hidden text. Attach an image or video thumbnail too.
Step 2
Add tasks
Define what recipients must do — subscribe on YouTube, follow on Instagram, join a Telegram group — and set a minimum time they must spend on each.
Step 3
Share the link
Get a Web link and a Telegram Mini App link instantly. Copy and share. The system can post to your channel automatically too.
Features

Everything you need, nothing you don't

Simple enough for first-timers, powerful enough for power users.

3 content modes
Hide a destination URL, generate a random secret key, or store a hidden message. Pick the mode that fits your use case.
Real verification
The system checks that recipients actually stayed on the task page for the required time. Only users who genuinely complete each step get through.
Telegram Mini App built in
Every link works in both a standard web browser and as a Telegram Mini App — no extra configuration required.
All major platforms supported
YouTube, TikTok, Instagram, Facebook, Telegram, Twitter, Discord, Twitch, WhatsApp, LINE, and more — all with proper icons.
Automatic dark mode
Theme adapts to the user's system preference or Telegram color scheme — light and dark handled automatically, no extra work needed.
Firebase Realtime Database
Payloads stored on Firebase. Every update reflects instantly. Supports both short IDs and AES-256 encrypted URL parameters.
